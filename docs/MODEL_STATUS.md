# Model status: documented vs implemented

**Scope.** This page compares the monographs and `README.md` with the code at commit `9fc339a`. `1A` means `Document 1A.md`, and so on. Status values: **Computed** (a solve or calculation in the repository), **Parameterised** (typed values stand in for a solve), **Closed-form** (an explicit expression, possibly anchored to literals), **Present, not wired** (code exists but is not called or not connected), **Not yet implemented** (described but absent). "Inferred" marks code read but not run.

## Reading

Today the code computes household value functions and stationary distributions through toolkit calls (`WelfareDecomposition_4Region.m:17, 22, 166, 192`), an intergenerational transition operator (`Build_IntergenTransitionMatrix.m`) and a counterfactual suite (`PolicyExperiment_LeeSeshadri_4Region.m:93`). Prices, the intergenerational stage, the transition path, fertility and bargaining, the actuarial audit and the attribution layers are parameterised or closed-form, so the headline figures in the documents correspond to outputs under assumed prices where the component is parameterised, and to typed anchors where it is closed-form. The `ndc` and `coalition_2024_shocks` branches are ahead of `main`, so this page describes `main` at `9fc339a` only; it records a status, not a verdict.
